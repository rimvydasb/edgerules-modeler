Today the Project page stacks two bars (host bar + Shell bar), shows the mark twice, and keeps an open project as a browser-like tab with ✕. The spec already asks for “one line, not two”. Four ways to fix it:

AOne lineRecommended

Library pages: mark + name, Examples, Workspace, last project. On a project the name collapses to the mark, nav cells become icons, and the Shell row moves up into the same 41px line. The project name ▾ is the project menu (recent projects, origin, duplicate).

BTwo tiers, clear owners

Keep two rows but give each one job. The host row (32px, quieter) is the site; the Shell row is the project. No second mark, no ✕ tab: the project is a crumb.
